## 📌 Project Overview

Managing personal finances can become difficult when income and expenses are recorded without a clear overview.

**Personal Expense Dashboard** provides a centralized interface for recording and analyzing financial transactions. The application focuses on making financial information easier to understand through structured transaction management, categorization, summary information, and visual representations.

The project was developed using **React** with **Vite**, following a component-based frontend architecture and a responsive dashboard-oriented user interface.

## 🚀 Getting Started

Follow the steps below to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Keerthanathiruppathi/Personal-Expense-Dashboard.git
```

### 2. Navigate to the project

```bash
cd Personal-Expense-Dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Vite will provide a local development URL, typically:

```text
http://localhost:5173
```

Open the URL in your browser.
